Offline preview and equation export use KaTeX 0.19.1 (MIT, https://github.com/KaTeX/KaTeX), mathml2omml 0.5.0 (LGPL-3.0-or-later, https://github.com/fiduswriter/mathml2omml), and @xmldom/xmldom 0.9.12 (MIT, https://github.com/xmldom/xmldom).
The complete mathml2omml corresponding source is supplied in web/vendor-sources/mathml2omml. Rebuild with npm ci && npm run build in web/. Local package replacements can be rebuilt with the same command.
